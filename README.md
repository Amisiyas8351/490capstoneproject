# GC-TRAC: SPLC Transportation Analysis
This project analyzes transportation accessibility and its relationship to civic participation across Mobile County and Baldwin County in the Alabama Gulf Coast region. The analysis focuses on transportation barriers such as limited vehicle ownership, public transportation access, polling location accessibility, and travel distance to polling sites. Using GIS mapping, transportation datasets, and demographic information, the project identifies geographic areas where transportation limitations may affect access to voting locations and other civic activities.
The analysis found that transportation barriers were more concentrated in several areas of Mobile County, particularly in communities with higher no-vehicle rates and limited public transit coverage. Baldwin County generally showed lower transportation barriers and higher levels of vehicle access. The project also found that transportation challenges differed between urban and rural areas, with some communities facing limited public transit options while others faced longer travel distances and fewer transportation resources overall.
Datasets utilized from:
U.S. Census Bureau American Community Survey (ACS)
Alabama Department of Revenue Motor Vehicle Division
Alabama Secretary of State Polling Location Data
ArcGIS Road Network and ZIP Code Boundary Data
Wave Transit System and BRATS Transportation Data
